# Smart Logistics Hackathon

Бэкенд-система для оптимизации логистических маршрутов с использованием open-source инструментов.

## Архитектура
Проект построен на базе:
- **FastAPI**: Основной бэкенд (порт 18000).
- **VROOM**: Математический движок для решения задачи VRP (порт 13000).
- **OSRM**: Движок маршрутизации для получения реальных дорожных данных.

## Текущие возможности
- Оптимизация маршрута для курьера с учетом реального времени проезда (OSRM).
- Симуляция дорожных инцидентов и автоматический пересчет маршрута.
- Vendor Lock-in Free: расчеты не зависят от платных API.

## Как запустить
1. Поднимите VROOM в Docker:
   ```bash
   docker compose up -d
   ```
2. Запустите бэкенд:
   ```bash
   ./myenv/bin/python -m uvicorn main:app --host 0.0.0.0 --port 18000 --reload
   ```

## API Эндпоинты
- `POST /plan-route`: Оптимизация набора точек.
- `POST /simulate-issue`: Пересчет маршрута при возникновении затора.
- `GET /health`: Проверка статуса систем.
